# Angiosome and Filler Related Blindness

This repository contains the data and code required to reproduce the reduced-order computational fluid dynamics network model used to study angiosome anatomy, choke resistance and filler-related visual loss.

The repository is intended to support journal review, computational reproducibility and subsequent DOI archival through GitHub and Zenodo.

## Repository contents

### `data/`

This folder contains the simulation outputs generated by the reduced-order CFD network model:

- Baseline simulation outputs.
- Scenario evaluations.
- Stress-test outputs.
- Choke-sensitivity outputs.
- Combined supplementary data CSV.
- Five-tab Excel supplementary data workbook.

The Excel workbook preserves the five principal supplementary datasets as separate worksheets. The combined CSV provides a single-file version of the same outputs with dataset identifiers.

### `code/`

This folder contains the Python reproducibility script used to:

- generate the virtual intravascular exposure cohort,
- solve the reduced-order CFD network,
- evaluate the prespecified simulation scenarios,
- run choke-resistance sensitivity analyses,
- generate figures,
- export CSV outputs.

## Model summary

The model simulates facial-to-ophthalmic filler transport using a reduced-order CFD network. Flow is governed by pressure-driven laminar conductance with Poiseuille resistance, branch-angle loss, Carreau shear-thinning filler rheology and finite-volume bolus transport across route dead volume.

The computational design includes 12,000 baseline virtual intravascular exposure profiles. These profiles are re-evaluated across eight prespecified CFD scenarios, giving 96,000 scenario evaluations. Choke-resistance sensitivity is reported separately across upstream and downstream implementations.

The outputs are conditional on intravascular exposure. They should not be interpreted as estimates of clinical incidence.

## Reproducibility

The Python script uses a fixed random seed and contains the model equations, parameter sampling, scenario definitions and output-export steps. The CSV and Excel files are generated outputs from this script.

Recommended workflow:

1. Review the `data/` folder for the submitted simulation outputs.
2. Review the `code/` folder for the executable reproducibility script.
3. Run the script in a Python environment with the required scientific libraries installed.
4. Compare regenerated CSV outputs with the supplied files.
